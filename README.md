# 경기장 좌석 배치도 (volleyball)

잠실학생체육관(SK 나이츠) · 장충체육관 좌석 배치 및 사석 관리 도구.

## 구성
- `index.html` — 전체 앱 (좌석 데이터 내장, 빌드 불필요)
- `api/state.js` — 공유 저장소 API (Vercel 서버리스 함수, 외부 패키지 없음)

## 기능
- 구역 클릭 → 코트 방향 그대로 좌석 그리드
- 사석 클릭 토글 / 드래그 일괄 지정·해제 (시작 좌석 상태의 반대로 적용)
- 사석 지정 시 메모 기록 (해제는 기록하지 않음)
- 도면 휠 확대·축소, 확대 상태 드래그 이동
- 층 필터, 확인 필요 항목 체크리스트
- 저장/불러오기(JSON), 엑셀 내보내기(요약·좌석목록·변경내역·메모기록·확인항목)

## 저장 방식
1. **기본**: 접속자 브라우저에 자동 저장 (localStorage)
2. **공유 저장소 연결 시**: 모든 접속자가 같은 사석·메모·체크 현황을 봄
   - 변경 후 1.2초 뒤 자동 저장, 15초마다 자동 새로고침
   - 상단 배지에 연결 상태 표시

## 배포
1. Vercel → Add New → Project → 이 저장소 Import
2. Framework Preset **Other**, 설정 기본값 그대로 Deploy

## 공유 저장소 활성화 (선택, 무료)
1. Vercel 프로젝트 → **Storage** 탭 → Create Database → **Upstash for Redis** (Free)
2. 프로젝트에 Connect (모든 환경 체크) → 환경변수 자동 등록
3. **Redeploy** 한 번
4. 사이트 상단에 "공유 저장소 연결됨" 표시가 뜨면 완료

연결 전까지는 자동으로 브라우저 저장 모드로 동작합니다.

> 주의: 공유 저장소는 URL을 아는 누구나 읽고 쓸 수 있습니다. 내부 공유 용도로 사용하세요.

## 데이터 갱신
`index.html` 교체 → commit → push 하면 Vercel이 자동 재배포합니다.

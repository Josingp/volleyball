# 좌석 확인증 시스템 (신인감독 김연경2 직관)

초청자가 **이름 + 휴대폰 뒤 4자리**로 본인 좌석을 확인하는 모바일 확인증 웹앱.

| 페이지 | 용도 |
|---|---|
| `/check.html` | 초청자용 — 좌석 조회 후 실시간 확인증 표시 |
| `/verify.html` | 스태프용 — 확인증 QR 스캔 시 위·변조 검증 결과 |
| `/admin-check.html` | 관리자용 — 명단 업로드(전체 교체), 행사 정보 수정, 키 변경 |

## 운영 방법

1. `/admin-check.html` 접속 → 관리자 키 입력
2. 행사 정보 확인/수정 (8/27 장충 행사로 전환할 때도 여기서 날짜·장소·만료일만 바꾸고 명단 재업로드)
3. 엑셀에서 `이름 / 전화번호 / 구역 / 열 / 번호` 5개 열을 복사해 붙여넣고 업로드
   - 한 사람 여러 좌석 = 좌석 수만큼 행 반복
   - 전화번호는 전체를 넣어도 뒤 4자리만 사용
4. 초청자에게 `/check.html` 링크 전달

## 위조·도용 방지 설계

- **명단 암호화 저장**: 저장소의 `data/checkdb.json`에는 평문이 없음.
  조회키는 HMAC-SHA256, 좌석 정보는 AES-256-GCM으로 서버에서만 암·복호화 (비밀키는 Vercel 환경변수 기반 — 저장소 열람만으로 명단 복원 불가)
- **본인 확인 2요소**: 이름 + 휴대폰 뒤 4자리 정확 일치 필요, 실패 사유 비노출
- **무차별 대입 차단**: IP당 분 8회 / 일 150회 제한 + 실패 시 지연
- **캡처·짜깁기 방어**: 확인증에 실시간 시계(서버 시각 동기화), 이름·발급시각이 박힌 무한 스크롤 리본, 카드 시머 애니메이션 → 정지 화면(캡처)은 현장에서 즉시 식별
- **현장 확인코드**: 매일 자동 변경되는 6자리 코드 — 스태프 대조용
- **QR 서명 검증**: 확인증 QR → `/verify.html` — 서버 HMAC 서명 검증으로 위·변조 즉시 판별, 행사 만료일 이후 자동 무효화

## 주의

- 관리자 키는 별도 보관 (분실 시 `data/checkdb.json`의 `adminKeyHash`를 새 키의 SHA-256으로 교체)
- 암호화 비밀키는 `APP_SECRET` 환경변수가 있으면 그 값, 없으면 `GH_TOKEN`에서 파생 → **GH_TOKEN을 교체하면 관리자 페이지에서 명단을 재업로드**해야 조회가 다시 됨
- 명단 업로드는 항상 전체 교체 방식 (부분 수정도 전체 재업로드)
